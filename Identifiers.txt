Identifers
==========

Identifers in python means the name given to anything to be identified. Ex:- variables, functions, classes, modules and other objects.

Rules for identifiers,

--Can contain:

    Letters (A–Z, a–z)

    Digits (0–9)

    Underscore (_)

    Example: user_name, age2, _count

--Cannot start with a digit

    ❌ 2value → invalid

    ✅ value2 → valid

--Cannot contain spaces or special characters

    ❌ user name, my-value, total$

    ✅ user_name, myValue

--Case-sensitive

    Name, name, and NAME are different identifiers.

--Cannot use Python keywords

    Keywords like if, else, for, class, def, etc. cannot be used as identifiers.
