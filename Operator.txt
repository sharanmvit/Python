Relational / Comparison Operators in Python
=================================================
1. == (Equal to)

Checks if two values are equal.

print(5 == 5)      # True
print(5 == 3)      # False

2. != (Not equal to)

Checks if two values are not equal.

print(5 != 3)      # True
print(5 != 5)      # False

3. > (Greater than)

Left value is greater than right.

print(7 > 4)       # True
print(2 > 8)       # False

4. < (Less than)

Left value is smaller than right.

print(3 < 9)       # True
print(10 < 2)      # False

5. >= (Greater than or equal to)

Left value is greater than or equal to right.

print(5 >= 5)      # True
print(7 >= 8)      # False

6. <= (Less than or equal to)

Left value is less than or equal to right.

print(4 <= 6)      # True
print(9 <= 2)      # False


Arithmetic Operators in Python
========================================

1. + (Addition)

Adds two numbers.

print(10 + 5)   # 15

2. - (Subtraction)

Subtracts right value from left.

print(10 - 3)   # 7

3. * (Multiplication)

Multiplies two numbers.

print(4 * 5)    # 20

4. / (Division)

Divides left by right (always gives float).

print(10 / 4)   # 2.5

5. % (Modulus)

Returns remainder.

print(10 % 3)   # 1

6. ** (Exponent)

Raises left to the power of right.

print(2 ** 3)   # 8

7. // (Floor Division)

Division but removes decimal part.

print(10 // 3)  # 3



Bitwise operator
=========================

& | ^ ~ << >> 

& (Bitwise AND)

Sets each bit to 1 if both bits are 1.

print(5 & 3)


Explanation:
5 → 101
3 → 011
Result → 001 = 1

2. | (Bitwise OR)

Sets each bit to 1 if at least one bit is 1.

print(5 | 3)


5 → 101
3 → 011
Result → 111 = 7

3. ^ (Bitwise XOR)

Sets each bit to 1 if the bits are different.

print(5 ^ 3)


5 → 101
3 → 011
Result → 110 = 6

4. ~ (Bitwise NOT)

Flips every bit (1 → 0, 0 → 1).
Also gives -(n + 1) in Python.

print(~5)


Output → -6

Because:
~5 = -(5 + 1)

5. << (Left Shift)

Shifts bits to the left → adds zeros on the right.
Equivalent to multiplying by 2ⁿ.

print(5 << 1)   # 5 * 2 = 10
print(5 << 2)   # 5 * 4 = 20

6. >> (Right Shift)

Shifts bits to the right → removes bits on the right.
Equivalent to dividing by 2ⁿ.

print(5 >> 1)   # 5 / 2 = 2

Membership operators are used to check whether a value exists inside a sequence (like list, tuple, string, set, dictionary).

Python has two membership operators:

✅ 1. in Operator

Returns True if the value is present in the given sequence.

Examples:
✔ In a list
print(5 in [1, 2, 3, 4, 5])     # True

✔ In a string
print("a" in "sharan")          # True

✔ In a dictionary (checks keys)
d = {"name": "Sharan", "age": 25}
print("name" in d)              # True
print("Sharan" in d)            # False   # checks key, not value

✅ 2. not in Operator

Returns True if the value is NOT present in the sequence.

Examples:
✔ In a list
print(10 not in [1, 2, 3])      # True

✔ In a string
print("z" not in "sharan")      # True

⭐ Summary Table
Operator	Meaning
in	True if value is found in sequence
not in	True if value is NOT found in sequence
