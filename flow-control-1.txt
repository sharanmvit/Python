FOR LOOP — NOTES (Python)
1. What is a for loop?

A for loop is used to repeat a block of code for each item in a sequence (like a string, list, tuple) or for a range of numbers.

It is mainly used when the number of iterations is known.

2. Syntax
for variable in sequence:
    statement(s)

3. Using range() in a for loop

range() generates a sequence of numbers.

Examples:

range(5) → 0,1,2,3,4

range(1,6) → 1,2,3,4,5

range(1,10,2) → 1,3,5,7,9 (step = 2)

Example:

for i in range(1,6):
    print(i)

4. Looping through a String
for ch in "Python":
    print(ch)


This prints each character one by one.

5. Looping through a List
numbers = [10, 20, 30]
for n in numbers:
    print(n)

6. Using break inside for loop

Stops the loop immediately.

for i in range(10):
    if i == 5:
        break
    print(i)

7. Using continue inside for loop

Skips the current iteration.

for i in range(5):
    if i == 2:
        continue
    print(i)

8. Using else with for loop

else executes only if the loop finishes normally (not stopped by break).

for i in range(3):
    print(i)
else:
    print("Loop completed")

9. Nested for loop

A loop inside another loop.

for i in range(3):
    for j in range(2):
        print(i, j)

10. Common Examples
a) Print numbers 1 to 10
for i in range(1,11):
    print(i)

b) Print even numbers
for i in range(2,21,2):
    print(i)

c) Print characters with index
name = "Sharan"
for i in range(len(name)):
    print(i, name[i])

What is continue statement?

The continue statement is used to skip the current iteration of a loop and move directly to the next iteration.

It does not stop the loop; it only skips one cycle.

2. Syntax
continue


Used inside:

for loops

while loops

3. Why do we use continue?

To skip:

unwanted values

specific conditions

invalid inputs

certain steps

Useful when you want the loop to keep running, but ignore some cases.

Examples
Example 1 — Skip number 3
for i in range(1, 6):
    if i == 3:
        continue
    print(i)

Output:
1
2
4
5


 When i == 3, the loop skips printing and jumps to next iteration.

Example 2 — Print only even numbers
for i in range(1, 11):
    if i % 2 != 0:
        continue
    print(i)

Output:
2
4
6
8
10

Example 3 — Skip empty inputs (real-world example)
names = ["Sharan", "", "Kumar", "", "Mbit"]

for n in names:
    if n == "":
        continue
    print(n)


Skips blank entries.

Difference Between break and continue
break	continue
Stops the loop completely	Skips only current iteration
Moves control outside loop	Moves control to next iteration
Ends execution of loop	Loop continues to run
⭐ Summary (Easy to Remember)

continue = skip & continue
break = stop & exit


BREAK in Nested Loops

When break is used inside a nested loop:

👉 It exits only the inner loop,
👉 NOT the outer loop.

Example 1 — Break inside inner loop
for i in range(1, 4):         # Outer loop
    for j in range(1, 6):     # Inner loop
        if j == 3:
            break
        print(i, j)

Output:
1 1
1 2
2 1
2 2
3 1
3 2


✔ Inner loop stops when j == 3
✔ Outer loop continues to next i

Example 2 — Break outer loop using a flag
stop = False

for i in range(1, 4):
    for j in range(1, 6):
        if j == 3:
            stop = True
            break
        print(i, j)
    if stop:
        break


✔ This breaks both loops.

📘 CONTINUE in Nested Loops

continue works only inside the loop where it appears.

👉 It skips that iteration of the inner loop.
👉 Then inner loop continues normally.
👉 Outer loop is not affected.

Example 3 — Continue inside inner loop
for i in range(1, 4):          # Outer loop
    for j in range(1, 6):      # Inner loop
        if j == 3:
            continue
        print(i, j)

✔ j == 3 is skipped
✔ Other values continue normally

📘 Continue inside outer loop
for i in range(1, 4):
    if i == 2:
        continue
    for j in range(1, 4):
        print(i, j)

loop with else block
====================
python allows else block at the end of for /while loop
 this else exceutes only if the loop exits normally ie without any break keyword.
 Else runs when:

Loop finishes all iterations

Condition in while loop becomes false

No break was executed

🔹 Else does NOT run when:

Loop is exited using a break statement

<b>Loops with else Block in Python — Notes</b>

1. The else block runs only if the loop completes normally without a break.

2. When else runs:
   • Loop finishes all iterations (for)
   • Condition becomes false (while)
   • No break encountered

3. When else does not run:
   • Loop is exited using break

----------------------------------------------

<b>For Loop with Else</b>
for i in range(5):
    print(i)
else:
    print("Loop completed")

Loop completed

----------------------------------------------

<b>For Loop with Break (Else Skipped)</b>
for i in range(5):
    if i == 3:
        break
    print(i)

    print("This will not run")

    print("While loop ended")

del
===
===
What is del?

del (delete) is a Python statement used to delete objects, such as:

variables

list items

dictionary keys

slices

entire objects

It removes the reference to the object from memory.

📌 1. Deleting a Variable
x = 10
del x
print(x)   # Error: x is not defined


✔ x is removed from memory.

📌 2. Deleting an Item from a List
numbers = [10, 20, 30, 40]
del numbers[1]
print(numbers)

Output:
[10, 30, 40]


✔ Element at index 1 (20) is deleted.

📌 3. Deleting a Slice from a List
nums = [1, 2, 3, 4, 5]
del nums[1:4]
print(nums)

Output:
[1, 5]


✔ Removes index 1 to 3.

📌 4. Deleting Dictionary Key
student = {"name": "Rahul", "age": 21}
del student["age"]
print(student)

Output:
{"name": "Rahul"}


✔ Key "age" is removed.

📌 5. Deleting an Object / Attribute
class Car:
    color = "Red"

del Car.color


✔ Deletes class attribute.

📌 6. Deleting Multiple Variables
a, b, c = 1, 2, 3
del a, b
print(c)


✔ Deletes a and b.

🛑 Important Notes

After deleting a variable, using it causes NameError.

del removes references, but actual memory cleanup happens by Python’s Garbage Collector.

You cannot delete built-in types or keywords.

| Operation             | Example           |
| --------------------- | ----------------- |
| Delete variable       | `del x`           |
| Delete list item      | `del list[2]`     |
| Delete slice          | `del list[1:4]`   |
| Delete dictionary key | `del dict["key"]` |
| Delete multiple vars  | `del a, b`        |

| Situation                 | Why use `del`?          |
| ------------------------- | ----------------------- |
| Temporary data not needed | Clean program           |
| Remove list/dict items    | Manage data             |
| Free memory               | Speed & efficiency      |
| Clean corrupted records   | Data preprocessing      |
| Clear session or cache    | Security & optimization |
