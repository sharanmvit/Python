int
====

int is a Datatype in python which is used to represent whole numbers. (Intergral numbers)

This is represented by 4 methods:
1. Decimal (Base 10)
2. Binary (Base 2)
3. Octal (Base 8)
4. Hexadecimal (Base 16)  

# Example of int datatype
a = 10          # Decimal
b = 0b1010     # Binary
c = 0o12       # Octal
d = 0xA        # Hexadecimal        

base conversion
================
We can convert one base to another base value using the following methods
bin() - converts any base to binary
oct() - converts any base to octal
hex() - converts any base to hexadecimal
int() - converts any base to decimal
# Example of base conversion
a = 10
print(bin(a))   # Output: 0b1010
print(oct(a))   # Output: 0o12
print(hex(a))   # Output: 0xA

complex
=======
complex is a Datatype in python which is used to represent complex numbers.     
A complex number is represented as a + bj, where a is the real part and b is the imaginary part.    

# Example of complex datatype
a = 2 + 3j
b = 4 - 5j
c = complex(1, 2)   # 1 is the real part and 2 is the imaginary part    
d = complex(3)      # 3 is the real part and 0 is the imaginary part
e = complex()       # 0 + 0j
# Accessing real and imaginary parts
real_part = a.real   # Output: 2.0
imaginary_part = a.imag  # Output: 3.0

Typecasting
================

Typecasting in python is convert one type of data type to another type.
 
 There are five 5 in built type functions in python.

viz, int(), float(), str(), bool(), complex().

Ex:- 
# int to string
a = 10
b = str(a)
print(b)        # Output: '10'
print(type(b))  # Output: <class 'str'>

# float to string
pi = 3.14
s = str(pi)
print(s)        # '3.14'

# bool to string
flag = True
s2 = str(flag)
print(s2)       # 'True'

# list to string
lst = [1, 2, 3]
s3 = str(lst)
print(s3)       # '[1, 2, 3]'
