base conversion
================
We can convert one base to another base value using the following methods
bin() - converts any base to binary
oct() - converts any base to octal
hex() - converts any base to hexadecimal
int() - converts any base to decimal
# Example of base conversion
a = 10
print(bin(a))   # Output: 0b1010
print(oct(a))   # Output: 0o12
print(hex(a))   # Output: 0xA

Features of Set Datatype in Python
1. Unordered Collection

A set does not preserve the order of elements.

Elements may appear in any order when you print the set.

2. Stores Only Unique Elements

Sets automatically remove duplicates.

s = {1, 2, 2, 3}
print(s)   # Output: {1, 2, 3}

3. Mutable

You can add or remove elements using add(), remove(), discard(), etc.

But elements inside a set must be immutable (e.g., no lists).

4. No Indexing or Slicing

You cannot access elements by index like lists or strings.

s[0]   # ❌ Error

5. Supports Mathematical Set Operations

Sets support fast and efficient set theory operations:

Operation	Method	Meaning
Union	`set1	set2orset1.union(set2)`
Intersection	set1 & set2	Common elements
Difference	set1 - set2	Elements in set1 not in set2
Symmetric Difference	set1 ^ set2	Elements not common
6. Dynamic Size

Size of a set grows or shrinks automatically when elements are added or removed.

7. Highly Efficient (Uses Hashing)

Set operations like membership checking (in) are very fast.

10 in myset   # Fast lookup

8. Can Be Created Using Curly Braces or set()
s = {1, 2, 3}
s2 = set([1, 2, 3])

9. Supports Iteration

You can loop through set elements:

for i in s:
    print(i)

10. Frozen Sets (Immutable Version)

Python also provides frozenset, a version of set that cannot be changed.

NoneType in Python
1. What is NoneType?

NoneType is the datatype of the value None.

None represents absence of value, null, or nothing.

a = None
print(type(a))   # <class 'NoneType'>

Key Features of NoneType
1. Only One Value → None

NoneType has only one possible value, which is None.

2. Used to Represent “No Value”

Used when a variable or function has no meaningful value.

def test():
    pass

print(test())   # Output: None

3. Immutable

None cannot be changed or modified.

4. Used as Default Return Type

If a function does not explicitly return a value, Python returns None by default.

5. Used for Optional Variables or Placeholders

Commonly used to initialize variables before assigning actual values.

data = None

6. Used for Comparisons

To check if something is None, always use:

if x is None:
    ...


Not:

if x == None:  # Not recommended

7. Boolean Behavior

None is treated as False in boolean contexts:

if None:
    print("Hello")  # Will not run
